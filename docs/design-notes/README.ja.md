# 設計ノート

English version: [README.md](README.md)

- 更新日: 2026-07-25

Clove が「なぜこうなっているのか」を残す場所です。仕様そのものは
[docs/index.ja.md](../index.ja.md) から辿れる各ドキュメントが正で、ここには
**その仕様を選んだ理由と、選ばなかった案**を書きます。

Clove は Clojure 系の Lisp を土台にしていますが、意図的に外した機能と、
他言語から借りた記法があります。「Clojure ならこう書けるはずだが動かない」
という場面に出会ったとき、それが未実装なのか意図的な非対応なのかを
ここで判別できるようにしています。

## 一覧

| ノート | 決定 |
| --- | --- |
| [マクロを持たない](no-macros.ja.md) | `defmacro` を提供せず、構文は special form と reader で固定する |
| [名前空間区切りに `/` を使わない](namespace-separator.ja.md) | `foo/bar` を廃止し `foo::bar` に統一。キーワードは名前空間を持たない |
| [Clojure から採らなかったもの](differences-from-clojure.ja.md) | protocol / multimethod / 名前空間の出入り などを外した理由 |
| [インタプリタとネイティブビルドの2経路](two-phase-implementation.ja.md) | 同じ言語に対して実装を2つ持ち、ネイティブ側は「黙って諦めない」 |
| [型は任意注釈にとどめる](gradual-typing.ja.md) | 実行時の型検査はしない。型情報はツールとネイティブ最適化のために使う |
| [`mut` と `imut`](mutability.ja.md) | 既定は永続データ構造。`mut` は破壊的更新を明示する契約 |
| [他言語から借りた記法](borrowed-syntax.ja.md) | indexer / dot-chain / OOP風呼び出し / map 省略記法を入れた理由 |

## 読み方

各ノートは次の形で書いています。

- **決定** — 現在の仕様
- **理由** — そう決めた根拠
- **採らなかった案** — 検討して外したもの
- **確認方法** — 実際に手元で確かめるコマンド

「採らなかった案」は、後から同じ議論を蒸し返さないために残しています。
外した理由が現在も有効かどうかは別問題なので、前提が変わったと思ったら
再検討して構いません。
