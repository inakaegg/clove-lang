# コードスタイル（公開向け）

English version: [code_style.md](code_style.md)

このドキュメントは、公開リポジトリ向けの言語ルールをまとめたものです。

## 言語ポリシー

- CLI のヘルプ、エラーメッセージ、利用者に見える出力は英語にする。
- Rust / Clove ソースのコードコメントは英語にする。
- テストのコメントとメッセージも英語にする。
- 日本語のドキュメントは `*.ja.md` ファイルにのみ置く。

## 理由

- 公開リリースは、より広い読者が読めるようにするため。
- コードと CLI の言語を揃えることで、発見しやすさとサポートのしやすさが上がるため。
